## Fortnite Visual Chest Counter v0.3.3 — Stable

[Download the portable Windows ZIP](https://github.com/NEVARLeVrai/fortnite-visual-chest-counter/releases/download/v0.3.3/Fortnite-Visual-Chest-Counter-v0.3.3.zip)

- **Stats** shows saved personal results, a date or match chart, a five-match moving average, chest-type shares, a mode filter and records by mode. Open a match from its chart bar to see chest counts, Pirate Token odds and the live versus replay difference when available.
- **Discord** adds `/stats` for finished synchronized matches. Use `/stats player:` for a player's totals, average, best match and estimated Pirate Token chance. `/match` now completes its original Discord response directly and reports history read failures.
- **English small HUD** recovers weaker chest pop-ups in compressed 720p footage, marks strong matches as confirmed and avoids counting a pop-up twice when the map briefly covers it. Adapted from Gabriel Gomez's upstream commit [8d30c78](https://github.com/GabrielGzS/fortnite-visual-chest-counter/commit/8d30c78).

[Stats guide](https://github.com/NEVARLeVrai/fortnite-visual-chest-counter/blob/main/docs/guides/stats.md) · [App and Discord previews](https://github.com/NEVARLeVrai/fortnite-visual-chest-counter/blob/main/docs/previews/index.md)
