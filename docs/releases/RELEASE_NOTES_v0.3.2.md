## Fortnite Visual Chest Counter v0.3.2 — Stable

[Fortnite-Visual-Chest-Counter-v0.3.2.zip](https://github.com/NEVARLeVrai/fortnite-visual-chest-counter/releases/download/v0.3.2/Fortnite-Visual-Chest-Counter-v0.3.2.zip)

- At the lobby, a verified replay refreshes the Dashboard and the existing overlay counts, chest types and Pirate Token estimate. Verified openings are shown as confirmed. The original live counts stay in Compare replay.
- The Team and cumulative totals use the verified result once. A replay that finishes late leaves the next match’s live counter intact.
- Chest types are visible when **Show chest types** is enabled and the personal overlay template includes `{types}`. Replay reports can identify buried chests and spirit poster chests separately.

The first installation from this fork is manual and establishes trust in the fork’s signing keys. Existing fork users can install this signed release with the experimental in-app updater.
