## Fortnite Visual Chest Counter v0.3.4 — Stable

[Download the portable Windows ZIP](https://github.com/NEVARLeVrai/fortnite-visual-chest-counter/releases/download/v0.3.4/Fortnite-Visual-Chest-Counter-v0.3.4.zip)

- Recover faded French rare chest notifications using repeated readings and an independent multiplier check. A shifted normal chest notification can now refine the type of an opening already counted.
- Try an additional text scale when regular French or Brazilian Portuguese readings are weak. The Portuguese fallback still requires a sharp glyph and chest-object support.
- Associate local Fortnite replays by session ID when available. This allows verification when the replay's internal start time and filename differ. Verified counts update the original result in the local history and Discord.
- Show the actual scale and confidence of each scaled detection in Activity.

From v0.3.3, open **Settings → Check for updates**, then download and install the update. Your configuration, profiles and saved history are preserved.

The first installation from this fork is manual. Extract the portable ZIP to establish trust in the fork's signing keys. The in-app updater remains experimental. If it cannot install an update, use the portable ZIP and copy your config.toml and state/ into the new folder.
