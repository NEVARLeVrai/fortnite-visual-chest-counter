## Fortnite Visual Chest Counter v0.3.1 — Stable

[Fortnite-Visual-Chest-Counter-v0.3.1.zip](https://github.com/NEVARLeVrai/fortnite-visual-chest-counter/releases/download/v0.3.1/Fortnite-Visual-Chest-Counter-v0.3.1.zip)

- Returning to the lobby stops the counter and saves the match. The Dashboard and overlay retain the final live count until the next Battle Royale warmup resets the counter.
- Auto mode recognizes the Ranked Battle Royale Habanero playlist family, including Ranked Trio.
- Match history and replay verification still run when the match ends. The retained live count is counted once in cumulative totals.

The first installation from this fork is manual. Users already on the fork's v0.3.0 can use the experimental in-app updater, which checks this release against the fork's signing keys. The [v0.3.0 notes](RELEASE_NOTES_v0.3.0.md) describe the initial setup and the changes from upstream.
