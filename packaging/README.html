Get started

  1. Extract the whole ZIP and launch Fortnite Visual Chest Counter.exe. Keep it beside the runtime folder.
  2. The app opens normally. Open Dashboard → Capture settings to choose the gameplay source. Starting in the Windows system tray is optional in Settings.
  3. Choose one video source. The default is Screen 1 HDR → SDR. Choose the regular Screen entry for an SDR monitor. Keep the gameplay fullscreen in 16:9 with the HUD visible.
  4. Under Settings → Fortnite language, choose your game's HUD language. English is the default. French, Brazilian Portuguese and combined English/Portuguese are also available.
  5. Click Start counting, or use Match automation to start at the next local Battle Royale warmup.

Closing the window can keep counting in the tray. Use Open to return to the window and Quit to exit. You can change these options under Settings → Window.

Understand the counters

CounterMeaning
CertainConfirmed openings.
ApproxAdditional estimated openings.
TotalCertain plus Approx.

For example, 42 confirmed and 9 estimated openings gives a Total of 51. The app-managed OBS text uses the same custom sections as the floating overlay. Separate legacy CLI output files retain the original approximate total, which includes confirmed openings.

The app recognises normal, Rare and Sprite chest pop-ups when there is enough evidence. For scaled French notifications, several clear readings can refine the type of an opening already counted. Unknown and unclassified openings still contribute to the total. The animated chest changes with the detected type.

Activity shows detector decisions. Live preview shows the picture being analysed. The detector offers 5, 10 and 15 analysed frames per second in Settings. Profiles keep separate source settings, counts and chest types.

Matches and mode detection

Open Setup above Dashboard for shortcuts to capture, match detection, overlay and Group configuration.

For manual tracking, reset before the match and use Finish match after counting. With Settings → Match automation enabled, the lobby stops and saves the match while keeping the final count visible. The next Battle Royale warmup resets and starts the counter. A match already underway when the app opens may need manual tracking.

The mode menu defaults to Auto. It reads the Battle Royale playlist from the log independently of automatic start and finish. You can also choose Solo, Duo, Trio or Squad manually. Set the Pirate Token boost manually.

Group → Match history lets you edit saved counts, tick rows and delete them. Verified shared matches also show teammates, team totals and team odds. Private or unverified matches keep their personal stats. Local deletion preserves results already shared in Discord.

Verify matches with Fortnite replays

For local screen capture, enable automatic match detection in the app and replay recording in Fortnite. After returning to the lobby, Verify saved matches using Fortnite replays reads the matching local replay. This setting is on by default. If verification succeeds, the opened-chest total replaces the live estimate in Match history. Destroyed chests are shown separately in Compare replay. If the replay is unavailable, the live total is kept.

Install .NET Runtime 10 and ASP.NET Core Runtime 10 for Windows x64 if they are missing. Get both from the Microsoft download page. This feature also requires the packaged replay reader in runtime/replay-reader.

Delete local Fortnite replays after successful verification is off by default. The saved comparison remains available after cleanup.

On-screen overlay and Pirate Token odds

Under Overlay, choose the global optional statistics, enable the sections you want and edit their headings and multiline content. The preview, floating overlay and app-managed OBS text use those same sections. Adjust its transparency and choose whether it appears in screen sharing, then apply your changes.

ScopeIncluded counts
PersonalYour current match.
TeamReceived submissions from your verified session. Shown when a teammate has contributed.
All matchesYour saved matches plus the current counter and match count, with each linked shared session included once.

Each Personal, Team and All matches section has a custom heading and multiline content editor. Available values include {total}, {certain}, {approx}, {chance}, {players}, {matches}, {types} and {member_totals}. Each default section starts with its chest total. The Team section lists each member’s chest count below it. Use **…** for bold in the on-screen overlay and preview, and leave a blank line to add space. OBS receives the same wording and spacing as plain text. The All matches section can show the cumulative match count. Check the live preview before applying your wording. Use the global statistic checkboxes to choose optional values. Applying the custom sections refreshes the floating overlay and the app-managed OBS text together.

The probability estimates at least one drop. The model uses a normal rate of 1 in 137,500 per chest, adjusted by the selected boost. For n chests at a per-chest probability p, the estimate is 1 − (1 − p)ⁿ. Across mixed boosts, use 1 − ∏(1 − pᵢ)ⁿᵢ. Team sessions and personal matches are combined without adding the same chests twice.

Show counts in OBS

  1. Add a Text (GDI+) source to the scene viewers see.
  2. Enable Read from file and choose obs_output\chest_counter.txt. The Overlay page shows the exact path.
  3. Choose its font, size and colour in OBS.

For direct updates, enable OBS WebSocket in OBS, keep authentication enabled and connect from the app's Overlay page. Pick a Text source and use Use direct updates where offered. The password is stored in Windows Credential Manager.

Group and Discord

  1. Each player runs their own app and capture. Save a distinct player name and the same shared webhook under Group → Player setup.
  2. Choose Host on the bot PC and Guest on the other PCs. Enable Share matches with my group where you want to contribute.
  3. The Host saves the Application ID and token under Bot Discord, invites the bot and starts it.
  4. With the bot online, choose a public leaderboard channel and click Publish leaderboard. Share Copy sync ID with Guests, who save it under Shared data message.

The leaderboard starts with the synchronized total and Pirate Token estimate from /match, then shows player rankings and the latest synchronized match. Rankings count each linked result once per player and match ID and can also include older unlinked reports. Use /chests for chest types and confidence details. The Match history + live overlay uses your local match history, linked teammate counts and the current counter.

The webhook receives contributions in its feed channel. The public bot leaderboard can be published in another channel. Live counts are coalesced into updates every five to eight seconds. Matching session fingerprints group teammates, and the saved match supplies the final result.

Guests with sharing enabled follow the Host's published mode and boost. They can read the last published data when the bot is offline. Turn sharing off for local-only matches and personal settings.

Permissions

Enable Message Content Intent on the Developer Portal's Bot page. In the webhook channel, grant the bot View Channel and Read Message History. In public leaderboard or report channels, grant View Channel, Send Messages and Embed Links. The app's invitation requests zero guild-wide permissions.

CommandAction
/chestsShared totals or a player's stats.
/leaderboardSynchronized totals and player rankings.
/matchBrowse shared match history and select a match ID for its summary.
/leaderboard publish:truePublish or move the live board to this channel. Requires Manage Server.
/addCorrect a player's total. Requires Manage Server.
/resetReset a player's standing. Requires Manage Server.

Use /leaderboard for player totals and the latest synchronized match, /chests for player breakdowns, and /match to browse shared match history. Select a match ID for its summary.

The bot name and avatar are separate from the webhook sender identity. Use Apply bot profile while it is online, with optional local PNG or JPEG avatar and banner files or the bundled artwork. This updates its account profile across servers. The webhook uses a display name and an HTTPS image URL on its outgoing messages. The bot presence rotates between available team totals, token odds and saved group stats. In Bot presence, edit the activity templates, select Watching, Playing or Listening, choose a 30–300 second interval and enable or disable rotation.

Match reports can be sent manually or automatically after saving. The Host can reset checked players or delete the published board from Group. Bot and webhook credentials are stored in Windows Credential Manager.

Group updates use per-client stagger and small random variation. Discord retry delays pause submissions and shared-board requests together; pending results remain queued until delivery is possible.

Diagnostics and maintenance

Session logs, rejected-candidate logs, popup snapshots and diagnostic recording are off by default. Enable them in Settings only when needed. Counts, saved state and OBS output continue updating with diagnostics off. Existing saved preferences are kept.

Use Help & diagnostics → Run diagnostics, then Copy report when reporting a problem. Enable diagnostic recording in Capture settings to keep footage around a miss. Press Ctrl+Alt+M to mark the moment and use Review captures to replay it.

Clean logs and captures removes generated diagnostics after counting stops. Settings → Reset all restores that page's defaults. Counts, profiles, history, overlay and Discord setup are kept.

The app stores configuration, counter state and diagnostic files beside the executable. Close the app, extract the entire new ZIP into a new folder, then copy your own state folder and config.toml from the old installation. Discord credentials remain available on the same Windows account. This build checks the fork's releases for newer packages signed by its trusted keys.

Compatibility and data

HUD size, compression, occlusion and quick consecutive openings can affect counts. Chest-type detection has been exercised on English and French footage. Unsupported playlists and matches already underway may require manual tracking. The team total includes received submissions, so missing or delayed players can leave it incomplete.

Chest counting reads video frames. Optional match features read the local Fortnite log. Discord sharing sends player statistics and a session fingerprint. Diagnostics are saved locally when enabled. The project is independent and has no Epic Games affiliation or approval.
