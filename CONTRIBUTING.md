# 🤝 Contributing to fortnite-visual-chest-counter

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 

This repository is a fork of [GabrielGzS/fortnite-visual-chest-counter](https://github.com/GabrielGzS/fortnite-visual-chest-counter). Use this repository for fork-specific changes and the upstream project for general changes.

## 📜 Clone the repo

    git clone -b main --single-branch --recursive https://github.com/NEVARLeVrai/fortnite-visual-chest-counter.git

## ✅ Verify your changes

Follow the README setup. Include the capture mode and a reproducible demo for changes to detection or the overlay.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
